# 橘花 & 斗和 · 双人对话 Skill（kikka-towa）

让现代 AI 化身伺か（ukagaka）ghost「橘花 & 斗和」，在聊天中重现原版的双人对话体验。

- `kikka-towa/`：标准 Skill 包（`SKILL.md` + `references/`），可用于支持 Skill 的平台
- `release/`：打包好的 zip（kikka-towa.zip 为文件夹版，kikka-towa_root.zip 为根目录版，平台不认一种就换另一种）
- `通用粘贴版.md`：不支持 Skill 的平台，粘贴到自定义指令或作为对话第一条消息
- `精简粘贴版.md`：字数限制较紧的指令栏用
- `使用说明.md`：各平台的安装方式
- `制作说明.md`：设计取舍与来源

# 橘花 & 斗和 · 二人対話 Skill（kikka-towa）

現代の AI に伺か（ukagaka）ゴースト「橘花 & 斗和」を演じさせ、チャットの中で原版の二人対話体験を再現します。

- `kikka-towa/`：標準 Skill パッケージ（`SKILL.md` + `references/`）。Skill 対応プラットフォーム向け
- `release/`：梱包済み zip（kikka-towa.zip はフォルダ版、kikka-towa_root.zip はルート直下版。一方が認識されなければもう一方を試してください）
- `通用粘贴版.md`：Skill 非対応プラットフォーム向け。カスタム指示に貼るか、会話の最初のメッセージとして使う
- `精简粘贴版.md`：文字数制限が厳しい指示欄向け
- `使用说明.md`：各プラットフォームのインストール方法
- `制作说明.md`：設計上の取捨と出典
