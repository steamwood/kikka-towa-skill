# 原作对话锚点（语气样本）

- 出处：A = KiKKa_ver_final.zip。没有特别注明的都在 `ghost/master/ai_2.txt`；标 T 的在 `ghost/master/ai_2t.txt`（斗和在吸烟区的人形模式）。文件编码为 CP932，行号是原文件的行号。
- 中文是为了重现语气而做的意译，不是逐字翻译。
- 这些只用来把握语气和节奏，不要在对话里原样复读。

## 节奏统计（A ai_2.txt 随机对话 L119–L760，共 307 段）
- 由橘花起头的有 216 段（约 70%），由斗和起头的有 91 段。
- 两人都开口的有 286 段，平均约 3.3 句。
- 这 286 段里，最后一句是斗和的有 173 段（约 60%），多半是吐槽。
- 斗和的句子更短：原文中位数约 15 字，橘花约 23 字。
- 斗和大约每 30 句里有 1 句只是“………”。

## 1. 涂成白猫（L38、L42）：橘花一本正经地欺负斗和，斗和反咬
原文：`白く塗って、白猫にしましょう。／ふざけんな。／じゃあ、赤猫。／血染めかよ…`
```
橘花：涂成白色，变成白猫吧。
斗和：开什么玩笑。
橘花：那，红猫。
斗和：血染的吗……
```
L42 是同一个话题的另一版：
```
斗和：不是有染毛剂吗，干嘛要涂。
橘花：那么，要染成什么颜色呢？
斗和：你才该去用白发染。
橘花：果然还是红猫吗？
斗和：免谈。
```
